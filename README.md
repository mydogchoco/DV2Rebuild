# 드래곤빌리지2 오프라인 재구현

서비스 종료된 모바일 2D RPG **드래곤빌리지2**(하이브로, 2014)를, 추출한 원작 에셋으로
**싱글플레이 오프라인 게임(PC)** 으로 되살리는 개인 프로젝트입니다.

- **엔진**: Godot 4.7 / GDScript (원작은 Cocos2d-x)
- **타깃**: Windows PC, 마우스·키보드
- **목적**: 개인 소장·보존용. 배포나 수익화를 하지 않습니다.

> ⚠️ **이 저장소에는 원작 에셋이 전혀 들어 있지 않습니다.** 그림·음악·애니메이션·폰트
> 전부 존재하지 않습니다. 직접 작성한 코드와, 유실된 서버 데이터를 임의로 다시 세운 마스터 데이터가 전부입니다.

---

## 구현 상태

전체가 완성된 상태는 아닙니다. 또한 저는 라지드&문장 시스템 업데이트 전후로 게임을 접었습니다(사유: 수능). 따라서 그 이후의 게임 시스템과 업데이트에 대해서는 나무위키 문서로만 봤을 뿐, 잘 모릅니다.

1. 각성스킬 관련: 옛날 스킬의 경우 인플레에 밀린 경우가 많습니다. 기왕 좀 쓸만해졌으면 싶기도 하고, 귀찮기도 한 김에 중첩 불가 조건은 삭제했습니다. 한편 제가 가진 자료로는 초기 각성스킬 아이콘밖에 없어서 없는 아이콘들은 적당히 어울리는 것들로 돌려막기했습니다.

2. 베르나 업데이트~: 자료 부족으로 구현 사항에서는 제외하였습니다.

3. 2번과 연계되는 문제인데, 드빌2가 오랫동안 서비스되면서 ui 리워크 등 변화가 많다 보니 구버전/신버전 가리지 않고 유실분이 꽤 있습니다. 해당 부분들은 임의로 대체하거나 구현에서 제외하였으며, 따라서 원작과는 차이가 있을 수 있습니다. 

4. 멀티&온라인 시스템 관련: 서버 베이스가 아닌 솔로잉을 상정하고 만들면서 대부분의 멀티 기능은 구현에서 배제하거나 축소하였습니다. 피오드/라지드 레이드는 2번과 마찬가지 이유로 제외되었습니다. 관련 재회는 다른 방법으로 획득 가능하게 두었습니다.

5. 재화 관련: 다이아&골드는 상점에서 상호 변환을 통해 재화 파밍이 가능하도록 두었습니다. 

## 저장소 구성

```
scripts/
  core/       데이터 로더 · 세이브 · RNG · 씬 매니저 · 좌표 헬퍼
  systems/    순수 규칙 계층 — 전투·부화·성장·젬·장비 (화면을 모른다)
  ui/         화면과 입력
  tools/      에셋 변환 파이프라인(Python) + 헤드리스 검증(GDScript)
scenes/       .tscn
data/         마스터 데이터 46종 (유실된 서버 DB를 대신한다)
DV2/          ← 비어 있습니다.
```

계층 규칙은 단방향입니다 — `ui → systems → data`. 규칙 계층은 노드·스프라이트·사운드를
일절 모르고, 화면 없이 테스트할 수 있습니다.

## 실행하려면

**클론만으로는 실행되지 않습니다.** 원작 에셋이 없기 때문입니다.

1. DV2는 원래 원작 에셋이 있어야 할 자리입니다.
   
2. 변환 파이프라인을 돌려 `assets/converted/` 를 만듭니다.
   ```
   python scripts/tools/cocos_export.py <plist> <출력폴더>   # 아틀라스 → AtlasTexture
   python scripts/tools/spine_export.py <드래곤id> <단계>   # 스파인 → 중간 JSON
   godot --headless --script res://scripts/tools/build_all.gd  # 중간 JSON → .tscn
   python scripts/tools/build_fonts.py                      # 원작 BMFont 보정 + 한글 글리프 보강
   ```
3. Godot 4.7 로 엽니다. 메인 씬은 `scenes/main.tscn` 입니다.

원작이 구버전 Spine 포맷을 써서 `spine-godot` 런타임을 쓸 수 없기 때문에, 스파인은
**오프라인 변환기로 Godot 네이티브 씬을 굽는** 방식을 씁니다.

## 검증

로직 계층은 화면 없이 헤드리스로 돌립니다. 테스트는 `scripts/tools/test_*.gd` 에 있고,
`project.godot` 의 `[autoload]` 에 임시 등록한 뒤 다음처럼 실행합니다.

```
godot --path . --headless --quit-after 60
```

## 저작권

드래곤빌리지2의 모든 그림·음악·캐릭터·이름 등 원저작물의 권리는 **하이브로(Haebro)** 에
있습니다. 이 저장소는 그 저작물을 재배포하지 않습니다.

올라와 있는 것은 직접 작성한 코드와, 소실된 서버 데이터를 재구성한 데이터 파일입니다.
원작 에셋(그림·음악·스파인·비트맵 폰트), 코드는 모두 존재하지 않습니다.

이 프로젝트는 개인 보존 목적의 비영리 작업이며, 원저작권자의 요청이 있으면 따르겠습니다.
