# 드래곤빌리지2 오프라인 재구현

> **비공식 팬 프로젝트입니다.** 하이브로(highbrow)와 제휴·후원·승인 관계가 없으며, 공식 서비스가 아닙니다.
> *This is an unofficial fan project. Not affiliated with, sponsored, or endorsed by highbrow.*

서비스 종료된 모바일 2D RPG **드래곤빌리지2**(하이브로, 2014)를 **싱글플레이 오프라인 게임(PC)** 으로 재구현하는 개인 프로젝트입니다.

- **엔진**: Godot 4.7 / GDScript
- **타깃**: Windows PC, 마우스·키보드
- **목적**: 개인 소장·보존용. 원작 에셋 배포나 수익화를 하지 않습니다.

> ⚠️ **이 저장소만으로는 게임이 되지 않습니다.**
> 그림·음악·애니메이션·폰트 같은 원작 에셋이 없고, 대사·설명문 같은 표시 문자열도 없습니다.
> 올라와 있는 것은 직접 작성한 코드와, 게임을 돌리기 위한 수치·구조 데이터입니다.
> 업로드본의 코드에는 주석이 들어 있지 않습니다.

---

## 무엇이 들어 있고, 무엇이 없나

**있는 것**

- `scripts/` — 직접 작성한 게임 코드(GDScript)와 에셋 변환 파이프라인(Python)
- `scenes/` — 화면 구성(.tscn)
- `data/` — 마스터 데이터. 유실된 서버 DB를 대신하는 **수치·구조·식별자**입니다.
  스탯 곡선, 확률표, 스테이지 구성, 진화 트리, 연출 진행 순서 같은 것들입니다.
- `DV2/ORIGINAL/WildSP/` — 오리지널 캐릭터 원화
- `DV2/ORIGINAL/Loki/*.src.json` — 그림 없이 좌표만 담은 자체 포맷 메타데이터

**없는 것**

- **원작 에셋 일체** — 그림·음악·스파인 애니메이션·비트맵 폰트
- **표시 문자열** — 스토리 대사, 도감·아이템 설명문, 화면 안내 문구.
  코드가 읽는 자리는 비어 있고, 이름 자리에는 자리표시자가 들어 있습니다.
- **원작 클라이언트의 소스 코드**

`data/` 안에 원작에서 비롯된 문자열이 일부 남아 있습니다. 장비·젬처럼 **이름 자체가
식별자인** 항목들인데, 세이브 파일이 그 문자열을 그대로 담고 있어 바꾸면 기존 진행도가
깨집니다. 그 밖의 이름과 문장은 들어 있지 않습니다.

## 어떻게 만들었나

원작은 Cocos2d-x 로 만들어졌고, 서비스가 끝나면서 수치·규칙이 서버와 함께 사라졌습니다.
그래서 이 프로젝트는 **원작 게임의 동작을 분석해 Godot 위에 새로 구현**했습니다.
화면 배치와 연출 순서는 그 분석에서 얻었고, 전투 공식·밸런스처럼 서버에 있던 부분은
커뮤니티 위키와 플레이 영상을 참고해 **직접 설계**했습니다. 원작의 소스 코드는 이
저장소에 포함되어 있지 않습니다.

## 구현 상태

저는 라지드&문장 시스템 업데이트 전후로 게임을 접었습니다(사유: 수능). 따라서 그 이후의 게임 시스템과 업데이트에 대해서는 잘 모릅니다.
게임 시스템 구현 및 디테일은 나무위키와 유튜브 플레이 영상을 참고하였습니다.

1. 각성스킬 관련: 옛날 스킬의 경우 인플레에 밀린 경우가 많습니다. 기왕 좀 쓸만해졌으면 싶기도 하고, 귀찮기도 한 김에 중첩 불가 조건은 삭제했습니다. 없는 아이콘들은 적당히 어울리는 것들로 돌려막기했습니다.

2. 베르나 업데이트~: 자료 부족으로 구현 사항에서는 제외하였습니다.

3. 2번과 연계되는 문제인데, 드빌2가 오랫동안 서비스되면서 ui 리워크 등 변화가 많다 보니 구버전/신버전 가리지 않고 유실분이 꽤 있습니다. 해당 부분들은 임의로 대체하거나 구현에서 제외하였으며, 따라서 원작과는 차이가 있을 수 있습니다. 

4. 멀티&온라인 시스템 관련: 서버 베이스가 아닌 솔로잉을 상정하고 만들면서 대부분의 멀티 기능은 구현에서 배제하거나 축소하였습니다. 관련 재회는 다른 방법으로 획득 가능하게 두었습니다.

5. 재화 관련: 다이아&골드는 상점에서 상호 변환을 통해 재화 파밍이 가능하도록 두었습니다.

6. 드래곤 관련: 그래픽이 부재하는 드래곤은 다른 에셋을 대신 사용하도록 배선했습니다. 버그가 아닙니다.

## 저장소 구성

```
scripts/
  core/       데이터 로더 · 세이브 · RNG · 씬 매니저 · 좌표 헬퍼
  systems/    순수 규칙 계층 — 전투·부화·성장·젬·장비 (화면을 모른다)
  ui/         화면과 입력
  tools/      에셋 변환 파이프라인(Python) + 헤드리스 검증(GDScript)
scenes/       .tscn
data/         마스터 데이터 (수치·구조·식별자)
  text/       ← 표시 문자열 자리. 비어 있습니다.
DV2/          ← 원작 에셋 자리. 비어 있습니다.
  ORIGINAL/   └ 자작 원화와 좌표 메타데이터만 있습니다
```

계층 규칙은 단방향입니다 — `ui → systems → data`. 규칙 계층은 노드·스프라이트·사운드를
일절 모르고, 화면 없이 테스트할 수 있습니다.

## 실행하려면

**클론만으로는 실행되지 않습니다.** 원작 에셋이 없기 때문입니다.

1. `DV2/` 는 원작 에셋이 있어야 할 자리입니다. **암호화되지 않은** 추출본을 그대로 넣습니다.

2. 변환 파이프라인을 돌려 `assets/converted/` 와 생성 씬을 만듭니다.
   ```
   python scripts/tools/rebuild_assets.py     # 아틀라스·스파인·이펙트·폰트 전량 재생성
   godot --headless --path . --import         # 임포트 캐시 재생성
   ```
   무엇을 만들지 미리 보려면 `--list`, 일부만 돌리려면 `--only atlases dragons` 처럼 씁니다.

3. 표시 문자열을 넣습니다(선택). 없어도 게임은 돌아가고, 글자만 비어 보입니다.
   ```
   python scripts/tools/build_text.py         # 문자열 번들 → data/text/
   ```
   원작 문자열 번들에 있던 대사·안내 문구가 복원됩니다. 도감·아이템 설명문처럼 번들
   밖에 있던 문장은 나무위키를 참고하여 직접 작성해야 하므로 이 경로로 복원되지 않습니다.

4. Godot 4.7 로 엽니다. 메인 씬은 `scenes/main.tscn` 입니다.

원작이 구버전 Spine 포맷을 써서 `spine-godot` 런타임을 쓸 수 없기 때문에, 스파인은
**오프라인 변환기로 Godot 네이티브 씬을 굽는** 방식을 씁니다.

> 한계 둘. ① 일부 아이콘은 원작 아틀라스가 아니라 커뮤니티 위키 자료에서 복원한 것이라
> 이 파이프라인만으로는 다시 만들어지지 않습니다. ② 개발 과정에서 활용한 도구들을 빼 두었기
> 때문에 인트로 자산 반입과 아틀라스 2종의 좌표 보정 단계는 건너뜁니다(실패가 아니라
> 건너뛴 것으로 표시됩니다). 두 경우 모두 해당 자리만 비어 보입니다.

### `DV2/ORIGINAL/`

원작 덤프가 아니라 **외부에서 반입한 원본** 자리입니다. 자작 캐릭터 원화와, 그림 없이
좌표만 담은 자체 포맷 메타데이터(`*.src.json`)만 올라와 있습니다. 짝이 되는 그림은
원작 자산이라 올리지 않았으므로 그 자리는 비어 보입니다.

### 아이콘

`icon.png` · `icon.ico` 는 **Godot 엔진 기본 아이콘**입니다. 원작 앱 아이콘은 저작물이라
여기 올리지 않았고, 대신 같은 이름·같은 자리에 중립 아이콘을 두었습니다. 원하는 그림으로
바꾸려면 두 파일을 덮어쓰면 됩니다(`python scripts/tools/build_placeholder_icon.py` 로 기본값 복원).

## 검증

로직 계층은 화면 없이 헤드리스로 돌립니다. 테스트는 `scripts/tools/test_*.gd` 에 있습니다.

```
python scripts/tools/run_all_tests.py       # 컴파일 게이트 + SceneTree 테스트 전량
python scripts/tools/run_all_tests.py --list
```

러너는 `scripts/**/*.gd` 를 전부 컴파일해 본 뒤(화면 스크립트의 오타는 그 화면에 들어가야
드러납니다) 테스트를 하나씩 별도 프로세스로 돌립니다. 테스트는 실제 세이브를 열지 않고
전용 테스트 세이브를 쓰며, 끝난 뒤 실세이브가 그대로인지 해시로 확인합니다.

## 저작권

드래곤빌리지2의 세계관·캐릭터·이름·그림·음악 등 원저작물의 권리는 **하이브로(highbrow)**
에게 있습니다.

원작 에셋(그림·음악·애니메이션·폰트), 표시 문자열(대사·설명문), 원작 클라이언트의 소스
코드는 들어 있지 않습니다. 개발에 사용했던 일부 코드와 도구도
넣지 않았습니다 — 이 저장소는 **암호화되지 않은 온전한 에셋 폴더**를 `DV2/` 에 넣는 것을 전제합니다.

이 프로젝트는 개인 보존 목적의 비영리 작업이며, 원저작권자의 요청이 있으면 따르겠습니다.
